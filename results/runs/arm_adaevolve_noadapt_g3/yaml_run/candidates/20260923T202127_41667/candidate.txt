name: mockingjay_liveness_sm_v1
doc: >
  State Machine Liveness Invariants Specification:
  Logical States:
  - STATE_DEAD (-11): Fully decayed or predicted dead (RD > 73, unknown prefetch,
    writebacks). Maximal eviction priority under max_magnitude + prefer_negative.
  - STATE_OVERDUE (-10 to -1): Passed predicted reuse window without reuse;
    monotonically aging towards STATE_DEAD.
  - STATE_IMMINENT (0): Reached predicted reuse interval; maximum retention priority
    (magnitude 0).
  - STATE_ACTIVE (+1 to +10): Line with predicted future reuse; decaying monotonically
    toward 0.
  Liveness Invariants:
  - Invariant 1 (Monotonic Decay to Dead): In the absence of hits, all active lines
    MUST monotonically transition through STATE_IMMINENT (0) to STATE_DEAD (-11)
    via clamped_dec.
  - Invariant 2 (No Inverted Protection for Dead Lines): Lines predicted to exceed
    cache capacity (RD > 73) or dead prefetches MUST enter directly in STATE_DEAD
    (-11) rather than +11, preventing artificial retention caused by decaying toward 0.
  - Invariant 3 (Hit Rejuvenation): Hits rejuvenate lines to STATE_IMMINENT (0) if
    unpredicted or to STATE_ACTIVE (+RD/8) if predicted.

  - run: fill_access
===== NEW_WORDS =====


- name: clamped_dec
  place: value
  params: {field: state, min: {int: [-16, 0]}}
  means: >
    Reads the per_line state field at the visited way. If its signed value
    is greater than min, returns its value minus 1. Otherwise returns min.

- name: duel_bypass
  place: condition
  params: {table: table, index: signature, div: {int: [1, 16]}, field: state, min_rd: {int: [0, 127]}, force_rd: {int: [0, 127]}, selector: state}
  means: >
    Evaluates the core bypass condition: true if the table entry at the index is
    present, AND either (its value >= force_rd) OR (its value >= min_rd AND
    its value / div > the current value of the per_line state field at the
    victim way AND that field's value >= 0).
    The final result depends on ChampSim's get_set_sample_category(set) c:
    If c == 1, returns false (Leader A: never bypass).
    If c == 2, returns the core condition (Leader B: bypass enabled).
    Otherwise, returns the core condition ONLY IF the global saturating selector
    state field is >= its midpoint (e.g., 512 for a 10-bit counter).
    Only valid inside victim.bypass_when.

- name: update_bypass_duel
  place: step
  params: {selector: state}
  means: >
    Reads ChampSim's get_set_sample_category(set) c.
    If c == 1, increments the global saturating selector state field (clamped at max).
    If c == 2, decrements the selector field (clamped at 0).
    Otherwise, does nothing.
